Cómo usar Open Market

Pasos para publicar y editar sin Know-how técnico.

  1. Creá un token de GitHub con permiso repo (marcado arriba a la izquierda) y pegalo en "Conectar".
  2. En Publicaciones, tocá una existente o presioná + Nueva publicación.
  3. Cargá título, rubro, localidad, descripción y teléfono con código de área. Ese número es el que se ve debajo de la foto.
  4. En Foto, elegí una imagen de tu computadora (se reduce automáticamente) o pegá una URL. Al tocar la foto en la web se abre WhatsApp con ese número.
  5. Activá Destacado si querés que aparezca primero.
  6. Presioná Guardar en GitHub. En pocos segundos los cambios se ven en la web pública.
Sin token también podés trabajar: los cambios se guardan como borrador en este navegador y podés bajar el archivo con "Descargar JSON". Para publicar, necesitás conectar el token.

La web pública es playok24.github.io/open-market y este panel está en /admin/.
