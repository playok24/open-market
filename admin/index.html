Cómo usar Open Market

Pasos para publicar y editar sin Know-how técnico.

  1. Ingresá el PIN del panel (por defecto 1978). Se cambia en Configuración.
  2. Creá un token de GitHub con permiso repo (marcado arriba a la izquierda) y pegalo en "Conectar".
  3. En Publicaciones, tocá una existente o presioná + Nueva publicación.
  4. Cargá título, rubro, localidad, descripción y teléfono con código de área. Ese número es el que se ve debajo de la foto.
  5. En Foto, elegí una imagen de tu computadora (se reduce automáticamente) o pegá una URL. Al tocar la foto en la web se abre WhatsApp con ese número.
  6. Activá Destacado si querés que aparezca primero.
  7. Presioná Guardar en GitHub. En pocos segundos los cambios se ven en la web pública.

Solicitudes de negocios

  1. El formulario de la web pública envía un mensaje con ID y datos al WhatsApp del organizador.
  2. Copiá ese mensaje y pegalo en Solicitudes, tocá Convertir en solicitud.
  3. Revisá los datos, corregí lo que haga falta y tocá Aprobar: la publicación pasa a la lista principal.
  4. Recordá tocar Guardar en GitHub para que se vea en la web.
Sin token también podés trabajar: los cambios se guardan como borrador en este navegador y podés bajar el archivo con "Descargar JSON". Para publicar, necesitás conectar el token.

La web pública es playok24.github.io/open-market y este panel está en /admin/.
